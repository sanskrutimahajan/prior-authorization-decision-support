# Demo walkthrough

Follow the setup and demonstration steps in the README. Use invented patient names/identifiers and `reviewer@example.com` addresses only. The notification flow intentionally excludes these addresses.

Start with a supported lumbar case. Create and reopen it, save incomplete evidence (PT four weeks and symptoms two months, five flags Yes), and demonstrate 75% readiness. Complete the durations to six weeks and three months, recheck to 100%, then record a reviewer decision with a reason. Open decision history and return to the dashboard to show the saved status.

For AI assistance, paste `ai/evaluation/complete.txt`, extract, inspect the excerpts, resolve values and confirm before saving. Changing a value requires renewed confirmation; saving does not approve the case. Recheck requirements afterward.

Power BI demonstrates operational snapshot reporting. Refresh its semantic model before comparing with newer app records. Power Automate configuration and controlled notification testing are documented separately.
